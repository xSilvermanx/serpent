With the exception of very few functions all interactions between serpent and other resources happen serverside.
Every clientside event should only transfer infos to the server.
The server triggers appropriate serverside functions on other resources, which then relay back to the client ONLY on their side.
The server should remain in control as much as possible, even if that control is only by proxy.
Unless mentioned otherwise the events only fire AFTER the event has taken place. This is especially true for serpent events.
